## Projects

### 🎬 [LinkToVideo](https://linktovideo.org/)

An online website video generator that turns a public webpage into a smooth scrolling MP4 video.

Paste a webpage URL, select the preferred dimensions and scrolling speed, and create a video without installing a screen recorder, browser extension, or video editor.

**Highlights:**

- Convert public webpages into scrolling videos
- Export MP4 videos in desktop, mobile, portrait, and square formats
- Choose from different scrolling speeds
- Works directly in a modern web browser

👉 **Try it:** [Turn a webpage link into a video](https://linktovideo.org/)

### 🕵️ [Imposter Game](https://www.impostergame.pro/)

A free online social deduction word game for parties, classrooms, team-building activities, and remote gatherings.

Most players receive the same secret word, while the imposter receives a different word—or no word at all. Players describe their words, discuss the clues, and vote to identify the imposter.

**Highlights:**

- Supports 3–99 players
- Local and online multiplayer modes
- More than 30 word categories
- Over 3,500 word pairs
- Multiple modes, including Classic, Wereword, Hardcore, and Double Spy
- No download required

👉 **Play now:** [Play Imposter Game online](https://www.impostergame.pro/)

### ✈️ [Dear Passengers Guide](https://dearpassengers.net/)

An independent guide to *Dear Passengers*, the upcoming cooperative airline game developed by FLEXUS.

The website collects verified information about gameplay, crew roles, multiplayer, release timing, PC requirements, language support, trailers, and Steam availability.

**Highlights:**

- Gameplay and crew-role explanations
- Release-date updates
- Multiplayer and player-count information
- PC system requirements
- Trailer and developer information
- Facts separated from speculation

👉 **Read the guide:** [Explore the Dear Passengers game guide](https://dearpassengers.net/)

> DearPassengers.net is an independent informational website and is not affiliated with FLEXUS or the official game publisher.
